# 数据与材料来源声明

本作品使用以下公开数据与官方训练包，均仅使用其公开训练/验证部分，
未获取、未尝试获取隐藏测试数据与标签：

| 数据集 | 公开来源 | 使用方式 |
|---|---|---|
| A 气体传感器漂移 | UCI Machine Learning Repository, Gas Sensor Array Drift, ID 224（Vergara 等，2012）| 平台训练包 cpu-a-guide-20261110-v1 提供的 JSONL 转换 |
| B 滚动轴承剩余寿命 | XJTU-SY 滚动轴承加速寿命试验数据集（雷亚国等，西安交通大学）| 平台训练包 cpu-b-rul-20261110-v1 提供的 JSONL 转换 |
| C 涡扇发动机剩余寿命 | NASA C-MAPSS（Saxena 等，2008，NASA Ames Prognostics Data Repository）| 平台训练包 cpu-c-guide-20261110-v1 提供的 JSONL 转换 |

- 模型基线：各训练包随附的 checkpoint.npz 与 baselines 参考代码（赛题组提供），
  本作品按其续训协议从检查点继续训练，未重新初始化。
- 大模型：计划使用平台允许的官方基础模型（或 PyTRiO Sampler），参数量不超过 27B。
- 实验记录平台：SwanLab（账号 Liang，项目 smart-evolution）。
- 其余代码为队伍自研；官方 baselines 代码在 tools/baseline/ 中原样保留并标注来源。
