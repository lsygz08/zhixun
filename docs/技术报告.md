# 智训引擎技术报告（草稿，≤10 页）

## 1. 系统概述

智训引擎是一个在工业数据漂移条件下无人干预地自主维持并提升模型性能的系统。
针对平台三个 CPU 工业模型（A 气体识别、B 轴承剩余寿命、C 发动机剩余寿命），
系统从平台提供的检查点开始，在 CPU 环境完成每数据集 10 轮自主优化，
通过受控递归自改进（RSI）在隐藏测试流上提升模型成绩。

## 2. 方法设计

### 2.1 两层自进化
- 模型层自迭代：只做增量续训（保留权重、Adam 状态、标准化与目标缩放），
  候选模型必须通过门禁才允许替换当前最优，未通过即回滚（从磁盘恢复上一轮最优检查点）。
- 策略层自改进：每轮决策先"读历史"（此前轮次的指标轨迹与结论），
  依据历史调整学习率与轮数（连续劣化→降学习率；平台期→降学习率；改善→维持）。

### 2.2 五环节闭环（每轮）
监测（训练/验证特征分布漂移 + 指标轨迹）→ 诊断（过拟合/平台期/健康）
→ 决策（epochs、学习率；llm.enabled 时由 Qwen3.8-27B 决策，失败回退规则）
→ 实验（官方 baseline 续训引擎）→ 门禁（验证集主指标 vs 当前最优，方向感知）→ 采纳/回滚 → 记录。

### 2.3 门禁
- 主指标与方向按数据集：A macro_f1 越大越好；B/C rmse 越小越好。
- 任何一轮候选劣化即回滚，确保输出永远不差于平台基线（已验证三包全部优于基线）。

### 2.4 安全边界
- 动作白名单：只允许调整 epochs/学习率/续训轮数；数据口径、评测脚本、指标定义为禁改区。
- 迭代与预算上限：轮数上限（10）、总训练时长上限（max_training_seconds）、失败重试上限。
- 只读取平台公开 train/validation；不扫描数据目录、不读取隐藏测试流。

## 3. 平台任务适配

| 数据集 | 任务 | 输入 | 主指标（方向）| 续训语义 |
|---|---|---|---|---|
| A | 6 类气体识别 | 128 特征 | macro_f1 ↑（参考 accuracy）| 分类 softmax，类别名与平台一致 |
| B | 轴承剩余寿命 | 双通道 34 特征 | rmse ↓（辅助 mae）| 回归，目标分钟，输出非负截断 |
| C | 发动机剩余寿命 | 24 特征（settings+sensors）| rmse ↓（参考 NASA 非对称分）| 回归，目标循环，输出非负截断 |

官方基线代码（NumPy MLP + Adam + 确定性检查点）原样复用，保证预测协议
（分类输出 [{label,score}]、回归输出 {value}）与平台逐位一致。

## 4. 实验与结果（本地公开验证集）

10 轮自主闭环，每轮门禁：

| 数据集 | 基线 | 最优 | 提升 |
|---|---|---|---|
| A | macro_f1 0.714030 | 0.726366 | +1.7% |
| B | rmse 681.16 | 647.24 | -34 分钟（-5.0%）|
| C | rmse 52.8686 | 51.8463 | -1.9% |

门禁行为示例（B）：第 1-2 轮改善被采纳；第 3 轮候选 rmse 升至 691.9（劣化）被回滚；
后续轮学习率自适应下调后仍不优于最优，全部回滚，最终输出第 2 轮检查点——
保证"最差阶段"不落地，展示恢复速度与稳定性。
